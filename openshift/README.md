This directory is the installation directory for `openshift-install`.

## Generating install-config.yaml

Do not edit `install-config.yaml` directly. Use the script:

```bash
export PULL_SECRET='{"auths": ...}'
export SSH_PUBLIC_KEY_PATH="$HOME/.ssh/id_ed25519.pub"
./scripts/02-create-install-config.sh
```

The script:
1. Reads `openshift/install-config.yaml.example`
2. Substitutes variables (cluster name, base domain, region, VM size)
3. Injects `$PULL_SECRET` and the SSH public key
4. Writes `openshift/install-config.yaml`

---

## Critical: back up install-config.yaml before installing

`openshift-install create cluster` **consumes and deletes** `install-config.yaml`
during the installation process. Back it up before running:

```bash
cp openshift/install-config.yaml openshift/install-config.yaml.bak
```

The backup is also gitignored. Keep it locally only.

---

## After successful installation

```bash
# Set KUBECONFIG to use the cluster
export KUBECONFIG=openshift/auth/kubeconfig

# Verify
oc whoami
# Expected: system:admin
```

## SNO-specific install-config notes

The key fields that make this a Single Node OpenShift deployment:

```yaml
controlPlane:
  replicas: 1    # Single control plane node

compute:
- name: worker
  replicas: 0    # No separate worker nodes

networking:
  networkType: OVNKubernetes    # Required for SNO (OpenShiftSDN not supported)
```

The control plane node is automatically made schedulable when `compute.replicas: 0`.
This means workloads (including test applications) can run on the single node.
